# Doujar public materials

Doujar 的公开资料仓库，用于存放隐私政策、使用说明和 Chrome Web Store 展示资料。

- [Privacy Policy — English](https://raywill.github.io/doujar/PRIVACY-EN.html)
- [隐私政策 — 简体中文](https://raywill.github.io/doujar/PRIVACY-CN.html)
- [隐私政策语言入口](https://raywill.github.io/doujar/)
- [隐私政策源文件](PRIVACY.md)
- [反馈与隐私问题](https://github.com/raywill/doujar/issues)

GitHub Pages 从 `main` 分支的根目录发布静态文件。英文和中文政策分别使用独立页面 `PRIVACY-EN.html` 和 `PRIVACY-CN.html`，`index.html` 提供语言入口。

Chrome Web Store 的 Privacy policy URL 可直接填写英文版或中文版页面地址。

修改隐私政策时，请同步更新 `PRIVACY.md`、`PRIVACY-EN.html` 和 `PRIVACY-CN.html` 中的内容及更新时间。
